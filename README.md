## 🎯 主要功能

-   **每日抽狗狗**: 从群聊成员中随机选择一位成为你的“狗狗”。
-   **每日抽狗狗 / 抽主人**: 从群聊成员中随机选择一位成为你的“狗狗”或“主人”。
-   **头像展示**: 自动获取并发送被抽中成员的QQ头像。
-   **次数限制**: 可自由配置每人每日的抽取次数。
-   **智能排除**: 自动排除机器人自身、抽取者以及配置文件中指定的黑名单用户。
-   **@功能可选**: 提供带 `@` 和不带 `@` 的两种抽取模式。
-   **历史记录**: 查看你今天抽到的所有“狗狗”列表。
-   **数据持久化**: 抽取记录会自动保存在本地，机器人重启不影响。
-   **管理员工具**: 管理员可以随时重置当天的所有抽取记录。
-   **帮助菜单**: 内置详细的帮助说明，方便用户快速上手。
-   **一次性抽取**: 新增 `来随机吧` 命令，可一次性按各身份的剩余每日上限全部抽取并合并发送（默认不 @，结果会附带头像）。

-   **分别统计**: 狗狗与主人的抽取次数彼此独立，均遵循每日上限。

## ⚙️ 安装与配置

### 安装

1. 在插件市场搜索“抽狗狗”或“糯米茨”即可安装（请确保指向本 fork 的更新源）
2. 或者可以直接克隆源码到插件文件夹：
```
cd /AstrBot/data/plugins
git clone https://github.com/KayYiny/astrbot-plugin-chougou/
# 控制台重启AstrBot
```

支持面板配置了。

## 📦 依赖

本插件目前仅为 `aiocqhttp` 平台设计和测试，其他平台可能无法正常获取群成员列表。

## 💾 数据存储

插件的数据（每日抽取记录）存储在 `data/plugins/random_identity/identity_records.json` 文件中。
如果你之前使用过旧版本，旧记录文件 `dog_records.json` 会被迁移（复制）为 `identity_records.json`。仓库包含迁移脚本：`migrate_records.py`，在仓库根目录运行 `python migrate_records.py` 即可。
每日记录会在第二天第一次触发插件时自动重置。
