# 随机抽身份插件 v2.3.0 (Fork by KayYiny)

配置驱动式随机抽取插件：在 AstrBot 面板的插件配置中填写身份角色名称，即可使用对应指令随机抽取群友。每个身份每天只能抽取一次。

---

## 🎯 特性

- **配置驱动**：身份角色在插件面板中自由填写，支持任意名称
- **每日限抽**：每个身份每天只能抽取一次（不可配置）
- **头像展示**：自动获取并显示被抽中成员的 QQ 头像
- **智能排除**：自动排除 Bot 自身、发起者以及配置中的排除用户
- **@ 可选**：提供带 `@` 和不带 `@` 两种模式
- **批量抽取**：一次性抽取所有尚未抽取的身份
- **状态概览**：查看今日所有身份的抽取状态
- **数据持久化**：使用 SQLite 存储记录，重启不丢失
- **管理员工具**：管理员可重置今日所有记录

## ⚙️ 配置

在 AstrBot 面板的插件配置中设置：

| 配置项 | 说明 |
| :--- | :--- |
| `identities` | 身份角色列表，每行填写一个名称，如 `老婆`、`老公`、`兄弟` |
| `excluded_users` | 不会被抽中的 QQ 号列表 |

示例：在 `identities` 中填入 `老婆`、`老公`、`兄弟` 后，即可使用 `今日老婆`、`抽老公`、`今日兄弟@` 等指令。

## 📖 指令

| 指令 | 功能 |
| :--- | :--- |
| `今日{身份}` / `抽{身份}` | 抽取指定身份（不带 @） |
| `今日{身份}@` / `抽{身份}@` | 抽取指定身份并 @ 对方 |
| `我的身份` | 查看今日所有身份的抽取状态 |
| `来随机吧` | 一次性抽取所有尚未抽取的身份 |
| `重置记录` | **[管理员]** 重置今日记录 |
| `今日身份帮助` | 显示帮助和当前配置 |

## 💾 数据存储

抽取记录存储在插件目录下的 `data/identity_records.db`（SQLite 数据库）。每日记录在次日第一次触发指令时自动重置。
